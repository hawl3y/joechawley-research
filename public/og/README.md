# Open Graph Assets

## How the OG image works

The production OG image is generated by `app/opengraph-image.tsx` using `next/og`
(ImageResponse / Satori). It is statically rendered at build time and served at:

    /opengraph-image

Next.js automatically includes it as `og:image` in all pages that inherit the root layout metadata.
Pages that set their own `openGraph` or `twitter` metadata must spread `OG_DEFAULTS` and `TWITTER_DEFAULTS` from `lib/site.ts` to keep it.

No static copy is kept in this folder; fetch `/opengraph-image` to view the current image.

## Per-page OG images

To add a custom OG image for a specific route, create an `opengraph-image.tsx` inside
that route's directory. Example: `app/research/[project]/opengraph-image.tsx`.

## Dimensions reference

| Use case       | Size      | Aspect ratio |
|----------------|-----------|--------------|
| Default OG     | 1200×630  | 1.91:1       |
| Twitter card   | 1200×628  | ~1.91:1      |
| LinkedIn share | 1200×627  | ~1.91:1      |

The 1200×630 image works correctly for all three platforms.
