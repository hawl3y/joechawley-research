# v0.2.2: Favicon redesign
**Release date:** 2026-10-30

## Summary

The JH favicon was unreadable at tab size. It is redrawn for legibility at 16px and 32px. Commit `beb6600`.

## Changes

### Identity
- `app/favicon.ico` (16, 32, 48): cream square (#FAFAF8), navy border (#1E3A5F, 1px at 16, 2px at 32, 3px at 48), navy "JH" in Geist Black filling about 75% of the width, optically centered.
- 16px frame hinted by hand to the pixel grid (Geist Black letterforms, 1px letter gap) so both letters stay separate and sharp.
- `app/icon.png` (512): same design as the favicon.
- `app/apple-icon.png` (180): navy fill, cream "JH", no border.
- Preview of 16px and 32px on light and dark tab backgrounds: `docs/reviews/favicon-preview.png`.

## Not changed
- Site name, OG image, routes, slugs, and content.

Run `docs/reviews/Production-Validation-Checklist.md` against https://research.joechawley.com. Check `/favicon.ico`, `/icon.png`, and `/apple-icon.png` in a private window, since browsers cache favicons.
