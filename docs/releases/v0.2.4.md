# v0.2.4: Icon link fix
**Release date:** 2026-10-30

## Summary

In v0.2.3, `app/icon.svg` and `app/icon.png` sat side by side and Next.js emitted a `<link>` for the PNG only, so browsers never used the vector icon. Both icons are now linked. Commit `c0ef9cd`.

## Changes

### Identity
- `app/icon.svg` renamed to `app/icon1.svg` and `app/icon.png` renamed to `app/icon2.png`. Numeric suffixes make Next.js link both.
- `public/site.webmanifest` points to `/icon2.png`.
- CLAUDE.md branding note and deploy checks updated to the new file names.

## Not changed
- Icon artwork, site name, OG image, routes, slugs, and content.

## Verification
Run `docs/reviews/Production-Validation-Checklist.md` against https://research.joechawley.com. The page head links `/favicon.ico`, `/icon1.svg`, `/icon2.png`, and `/apple-icon.png`, and each URL returns 200.
