# v0.2.8: Repo split follow-up
**Release date:** 2026-10-31

## Summary

First release deployed from the new site repo. No visible site changes.

## Changes

### Repo split
- Site repo `hawl3y/joechawley-research` holds the site only; research sources are in the private `joechawley-research-sources` repo and pre-split history in `joechawley-research-archive` (see v0.2.7).

### Build fix
- The `research/` ignore rule added in v0.2.7 was unanchored and excluded `app/research/` and `components/research/`, so v0.2.7 did not build. The rule is now `/research/` and the folders are restored.

### Commit author
- All commits in the site and sources repos were rewritten to the `Hawl3y` GitHub identity so Vercel accepts deploys. Commit hashes changed; `v0.2.7` was moved once to the rewritten first commit (one-time exception, private repo).
