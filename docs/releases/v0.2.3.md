# v0.2.3: Favicon uses the shared H mark
**Release date:** 2026-10-30

## Summary

The JH favicon from v0.2.2 is replaced by the shared H mark from joehawley.com, so both sites use the same mark.

## Changes

### Identity
- Source artwork stored unaltered at `public/brand/hawley-logo.svg` (from https://joehawley.com/images/hawley-logo.svg): white rounded tile with the H cut out.
- The H cutout is filled with navy (#1E3A5F) in the generated icons so the mark reads on light and dark tabs. joehawley.com leaves it transparent.
- `app/icon1.svg`: vector icon for modern browsers.
- `app/favicon.ico` (16, 32, 48) and `app/icon2.png` (512): rendered from the SVG, transparent corners.
- `app/apple-icon.png` (180): rendered from the SVG with white corners, since iOS does not support transparency.
- Numeric suffixes (`icon1`, `icon2`) are needed so Next.js emits a `<link>` for both the SVG and the PNG; with `icon.svg` and `icon.png` only the PNG was linked. `public/site.webmanifest` points to `/icon2.png`.
- JH icon files removed (replaced). Preview: `docs/reviews/favicon-preview.png`.

## Not changed
- Site name, OG image, routes, slugs, and content.

## Verification
Run `docs/reviews/Production-Validation-Checklist.md` against https://research.joechawley.com. Check `/favicon.ico`, `/icon1.svg`, `/icon2.png`, and `/apple-icon.png` in a private window, since browsers cache favicons.
