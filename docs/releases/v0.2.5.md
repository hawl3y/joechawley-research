# v0.2.5: Homepage leads with current research
**Release date:** 2026-10-30

## Summary

The homepage now leads with the current project and the value question. Paused work moves to its own section.

## Changes

### Homepage
- Eyebrow line above the hero removed. The descriptor appears in the header only.
- Hero statement: "Research on how security organizations measure, prove, and communicate the value they deliver." (`SITE.mission.hero` in `lib/site.ts`).
- Current Research shows active projects only (Project 002). It follows project `status` in `content/projects/`, not the `featured` flag or a hardcoded slug.
- New "Earlier research" section below lists paused projects (Project 001) with the Paused badge.
- The project summary shows the working thesis once one exists (`thesisVersion` above 0), otherwise the research question.
- "Read Proposal" appears only when the project has a research proposal artifact. It no longer links Project 001's proposal from another project.
- The Research Progress tracker and Why This Matters follow the lead active project.

### Research listing
- `/research` sorts projects by status (active, planned, paused, completed), then by project number.

## Not changed
- Routes, slugs, and project content.
- Footer, About, and site meta description text.
