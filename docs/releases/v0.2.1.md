# v0.2.1: Social preview and site name on all page types
**Release date:** 2026-10-30

## Summary

Pages that set their own `openGraph` or `twitter` metadata replaced the root layout's object entirely, so their link previews lost the site name and the default social preview image. Those pages now keep both. Commit `4764b47`.

## Changes

### Metadata
- `OG_DEFAULTS` and `TWITTER_DEFAULTS` added to `lib/site.ts` (site name, type, locale, `/opengraph-image` at 1200x630).
- Spread into page-level metadata on: project overview, artifact pages, journal entries, About, and Publications.

## Not changed
- Page titles, routes, and slugs.
- Content and files in `research/`.

## Verification
Run `docs/reviews/Production-Validation-Checklist.md` against https://research.joechawley.com. Check `og:site_name` and `og:image` on one page of each type above.
