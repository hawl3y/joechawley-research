# v0.2.0: Rebrand to Joe C. Hawley · Research
**Release date:** 2026-10-30

## Summary

The public site moved from Tradecraft Labs to **Joe C. Hawley · Research** at https://research.joechawley.com. "Tradecraft Labs" remains the internal project name (repository, local folder, internal docs).

## Changes

### Identity
- Site name "Joe C. Hawley · Research", descriptor "Cybersecurity governance, risk, and value", defined in `lib/site.ts`.
- Canonical URL `https://research.joechawley.com` (`NEXT_PUBLIC_SITE_URL`, with the same fallback in `SITE.url`).
- Title format `<Page title> | Joe C. Hawley · Research`.
- Text wordmark in the header (Lora name, sans descriptor). Logo image removed.
- JH favicon set (navy on cream): `app/favicon.ico`, `app/icon.png`, `app/apple-icon.png`. Old favicon files removed from `public/`.
- OG image shows the new name, descriptor, and domain. `public/og/og-default.png` regenerated.
- Author byline "Joe C. Hawley" on journal entries, artifact pages, About, footer, and site metadata (`authors`, `creator`).

### Content and platform (since v0.1.0)

- Per-project stage lists in the stage tracker; `evaluation` stage added.
- Optional `researchQuestions` list on projects.
- Page title separators fixed; site name appears once.
- Prebuild check (`scripts/check-dashes.mjs`) fails the build on em or en dashes.
- New journal entries for Project 002.
